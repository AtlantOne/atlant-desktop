Маршрутизация

Старый переключатель заполнения
Дублирующий legacy-переключатель не используется Windows-ядром. Настройте «Заполнение пакетов» выше.
Резервное подключение через TCP
Не реализовано в текущем Windows-ядре. Выберите транспорт вручную.
Смена порта сервера
Не реализовано в текущем Windows-ядре.
Отдельный DNS через VPN
Отдельный переключатель не реализован в Windows-ядре. DNS зависит от TUN и правил маршрутизации.
Фоновый веб-трафик (Decoy)
Генератор фоновых запросов не реализован в Windows-ядре. Серверный decoy работает независимо.
Ранние данные QUIC (0-RTT)
Early data не используется: полезные данные требуют взаимной аутентификации.
